# Инструкция пользователя

> **Заготовка (Этап 2).** Инструкция будет дополнена, когда появится логика
> поиска и объединения дублей (Этап 3). Ниже — структура будущего документа.

## 1. Назначение

Виджет «Поиск и объединение дублей» находит и объединяет дубликаты контактов,
компаний и сделок в amoCRM.

## 2. Установка

_(placeholder)_ Установка приватной интеграции из амоМаркета, выдача доступа к
API (OAuth), указание адреса бэкенда и ключа безопасности.

## 3. Настройка

_(placeholder)_

- **Сущности** — для каких объектов искать дубли (контакты, компании, сделки).
- **Правила поиска (AND/OR)** — какие поля и в каких комбинациях считать
  признаком дубля.
- **Нормализация** — приведение телефонов, email, имён к единому виду перед
  сравнением.
- **Права на объединение** — кому разрешено объединять дубли.
- **Запрет создания дублей** — блокировка/предупреждение при сохранении дубля.

## 5. Объединение
