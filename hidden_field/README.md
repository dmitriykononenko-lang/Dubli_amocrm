# Hidden Field — управление видимостью полей и страниц (виджет amoCRM/Kommo)

Виджет гибко управляет **видимостью и редактируемостью полей, разделов и
страниц** amoCRM в зависимости от пользователя: скрывает поле полностью,
маскирует значение звёздочками, блокирует редактирование, наследует настройку
воронки. Также умеет скрывать пункты меню, разделы аналитики и воронки.
Настройка — через матрицу «поле × сотрудник».

> **Статус: заготовка (MVP-каркас).** Фронтенд-движок скрытия и матрица настроек
> уже есть; backend (хранилище матрицы + выдача конфигурации по текущему
> пользователю) и сверка DOM-селекторов на живом аккаунте — следующий слой.
> Полное описание — в [`docs/spec.md`](docs/spec.md).

## Режимы поля

| Код | Режим | Поведение |
|---|---|---|
| `O` | Открыть | Поле видно и редактируется как обычно (по умолчанию). |
| `S` | Скрыть | Поле скрывается полностью вместе с названием. |
| `*` | Звёздочки | Название видно, значение заменяется звёздочками; системные действия (клик-звонок) сохраняются. |
| `B` | Заблокировать | Поле и значение видны, но недоступны для редактирования. |
| `V` | Воронка | К полю применяется настройка воронки (наследование). |

## Структура

```
hidden_field/
├── manifest.json                 # locations, oauth:Y, настройки backend_url/api_token, advanced-флаг движка
├── script.js                     # точка входа AMOCRM.widgets: движок скрытия (MutationObserver) + матрица
├── templates/
│   ├── advanced_settings.twig    # матрица «поле × сотрудник» с массовыми операциями
│   └── card.twig                 # статус-панель в карточке
├── i18n/
│   ├── ru.json                   # русская локализация
│   └── en.json                   # английская локализация
├── images/                       # логотипы
└── docs/
    └── spec.md                   # техническое задание (v1.0)
```

## Сборка архива

Файлы виджета должны лежать в **корне** архива (`manifest.json` на верхнем уровне):

```bash
cd hidden_field && zip -r ../hidden-field-widget.zip . -x 'docs/*' 'README.md' && cd ..
```

## Что осталось (по этапам ТЗ)

- **MVP:** backend-хранилище матрицы (`/api/config`, `/api/meta`, `/api/matrix`),
  сверка DOM-селекторов amoCRM (помечены `// VERIFY` в `script.js`).
- **II:** применение режимов в списках и канбане; скрытие воронок, пунктов меню
  и разделов аналитики.
- **III:** блокировка смены этапов; виртуальные группы; адресация по отделам.
- **IV:** скрытие событий в ленте; полировка локализации EN; оптимизация скорости.
